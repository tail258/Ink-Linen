Ink & Linen is an Obsidian theme for reading, writing, and tending to your notes. Dark navigation frames a bright writing canvas, while cool ink tones, generous spacing, and a clear heading hierarchy give your content room to breathe.

## Design

| A calm workspace | A readable page | Considered details |
| :--- | :--- | :--- |
| Deep blue-gray sidebars, a dark tab bar, and muted blue accents. | Near-white pages, dark ink text, and a measured progression from title to body. | Fine borders, small corner radii, and coordinated tables, quotes, code blocks, and callouts. |

### The palette

| | Color | Role |
| :--- | :--- | :--- |
| **Night** | `#0B1015` | Outer frame and tab bar |
| **Slate** | `#17222D` | Navigation and sidebars |
| **Linen** | `#FBFBFC` | Writing canvas |
| **Ink** | `#1B2731` | Body text |
| **Blue** | `#365B75` | Links, accents, and interaction |

### Made for the page

- **Balanced typography.** Six heading levels, comfortable line spacing, and system font stacks for English and Chinese.
- **Subtle navigation.** File and folder icons, clear selection states, and a continuous dark sidebar.
- **Coordinated content.** Tables, blockquotes, inline code, fenced code blocks, tags, and callouts share the same restrained visual language.
- **A consistent appearance.** Both Obsidian's light and dark settings use this palette: dark navigation with a light note surface.

## Installation

**Requires Obsidian 1.13.0 or later**, as specified in the theme manifest.

1. [Download the theme](https://github.com/tail258/Ink-Linen/archive/refs/heads/main.zip) and extract the archive.
2. Inside your vault, create the folder `.obsidian/themes/Ink & Linen/`.
3. Copy `theme.css` and `manifest.json` from the archive into that folder.
4. Open **Settings → Appearance** in Obsidian and select **Ink & Linen** from the installed themes. Restart Obsidian if it has not appeared yet.

Your vault should contain:

```text
.obsidian/
└── themes/
    └── Ink & Linen/
        ├── manifest.json
        └── theme.css
```

The screenshots show the theme on Windows. Fonts may vary with the fonts available on your system.
